The search box at the top of the window searches everything you have connected, so you do not have to remember where a document lives before you can find it.

## What it covers

| Group | Contents |
| --- | --- |
| **Project files** | Documents in the current project |
| **Notion** | Pages in your connected workspace |
| **Google Drive** | Files in your connected Drive |

Notion and Google Drive appear only when connected. See [Notion](/sources/notion) and [Google Drive](/sources/google-drive).

## Using results

- Selecting a **project file** opens it in a tab.
- Selecting a **Notion page** or **Drive file** imports it into the current project and opens it.

That second behaviour is the useful part: searching is also how you pull something in. You do not have to browse to a page in the Sources tree if you already know its name.

Results are labelled **Untitled** when the source has no title of its own.

## Searching inside a document

Search finds documents. To find text within the document you have open, use the editor's own **Find** (`⌘F`) and **Find and Replace** (`⌘⇧H`).

## Asking the assistant instead

For questions rather than lookups — *which documents mention pricing, and what do they say?* — ask in chat. The assistant searches project content and filenames and tells you what it found, with the documents it read shown as tool cards. See [Chat with the assistant](/ai/chat).
