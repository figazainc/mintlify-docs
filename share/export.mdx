---
title: "Exporting documents"
description: "Turn a document into a PDF, DOCX, PPTX, or Markdown file, or share it straight from the app."
---

Exporting produces a file you can attach, upload, or hand over. It is a one-off snapshot — unlike [publishing](/share/publish), an exported file does not stay in sync.

## Export a document

From the document tab menu (or by right-clicking the document in the sidebar), choose **Export as** and pick a format.

| Document type | Available formats |
| --- | --- |
| Documents | **PDF**, **DOCX**, **Text file (Markdown)** |
| Slide decks | **PDF**, **PPTX**, **Text file (Markdown)** |

The formats offered depend on what the document is. A slide deck exports as a presentation rather than as a Word document, because that is what a deck is for.

While an export runs you see **Exporting…** — and for slide decks, a slide-by-slide progress readout, since each slide is rendered before the file is assembled.

## Share without saving a file

**Share as** offers two lighter options:

- **Copy content** puts the document on your clipboard for pasting somewhere else.
- **Share content** hands the document to your operating system's share sheet — email, messaging, whatever you have set up.

## Which to use

| You want to | Use |
| --- | --- |
| Attach a document to an email or a ticket | **Export as** PDF or DOCX |
| Present a derived pitch | **Export as** PPTX, or open the deck in the slide viewer and present from Figaza |
| Move content into another tool by hand | **Share as → Copy content** |
| Keep a living copy your colleagues can read | [Publish to Drive or Notion](/share/publish) |
| Work on the same project from another machine | [Remote sync](/share/sync) |
