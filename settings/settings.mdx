Open **Settings** from the user menu at the bottom of the sidebar.

## General

Appearance and language for the app itself.

| Setting | What it does |
| --- | --- |
| **Theme** | Light, dark, or follow your system |
| **App language** | The interface language |
| **Interface zoom** | Scales the whole interface for readability — **Zoom in**, **Zoom out**, **Reset zoom** |
| **Voice language** | The language used for voice mode in chat |

Theme and language are also available directly in the user menu.

Interface zoom scales everything. To scale just the document you are reading, use the zoom controls in the editor toolbar instead.

Choosing a **Voice language** is what enables the microphone in chat — see [Chat with the assistant](/ai/chat).

## Account

Your signed-in profile and subscription: your current plan, **Manage subscription**, and **Sign out**.

If your company holds the subscription, the plan is shown as managed by that company. See [Plans and billing](/settings/plans-and-billing).

## Skills

Create, edit, and customise the saved prompts you run with `/`. See [Skills](/skills/quickstart).

## AI

| Setting | What it does |
| --- | --- |
| **YOLO mode** | Automatically accepts all AI changes without showing them for review |
| **MCP servers** | Connect agents to external tools |

<Warning>
  **YOLO mode** removes the review step for every AI change, including those made by background agents you are not watching. See [Reviewing AI changes](/ai/reviewing-changes).
</Warning>

See [MCP servers](/integrations/mcp-servers).

## Integrations

The data pipelines for the current project, and the **Stored credentials** they use. See [Integrations](/integrations/overview).

Integrations are per-project, so this tab needs a project open.

## Sync

Sync the current project's full history to a Git remote you control. See [Remote sync](/share/sync).

<Note>
  This tab appears only when remote sync is enabled in your build of Figaza.
</Note>

## Privacy

Usage data sharing and the zero-data-retention model restriction. See [Privacy](/settings/privacy).
