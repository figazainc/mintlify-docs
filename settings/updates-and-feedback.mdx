## Updates

Figaza checks for new versions and prompts you when one is available.

| Prompt | What it means |
| --- | --- |
| **Update Available** | A newer version is ready. Choose **Update Now**, or **Later** to keep working |
| **Update Required** | This version is no longer supported. You must update to continue, and the only action is **Close Application** |

Updates install themselves — there is nothing to download by hand.

## Sending feedback

Choose **Send feedback** from the user menu.

<Steps>
  <Step title="Choose a type">
    **Bug Report** or **Feedback**.
  </Step>
  <Step title="Pick a category">
    **Crash / App freeze**, **UI / Visual issue**, **Data loss / Corruption**, **Slow performance**, or **Other**.
  </Step>
  <Step title="Describe it">
    A brief **Title**, and a **Description** with the details. Description is optional, but a bug report without one is much harder to act on.
  </Step>
  <Step title="Submit">
    You get a confirmation when it is received.
  </Step>
</Steps>

<Tip>
  For a bug, the three things worth including are what you were doing, what you expected, and what happened instead. If it involves a specific document or project, say which — and whether it happens every time or occasionally.
</Tip>

<Note>
  If **Send feedback** is not in your user menu, it is not available in your version of Figaza.
</Note>
